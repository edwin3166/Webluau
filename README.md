# Velum Luau Obfuscator

High-strength pure JavaScript Luau obfuscator with custom virtual machine protection.

## Features

- Custom bytecode VM
- 4-layer encryption
- Integrity verification
- Anti-analysis checks
- Junk instructions & opaque predicates
- Clean dark web interface

## Deploy on Render

1. Create a new **Static Site** on Render
2. Upload this folder (or connect a Git repo containing these files)
3. Set the publish directory to the root of this project
4. Deploy

The site is fully static — no backend required.

## Local usage

Just open `index.html` in a browser, or serve the folder with any static server.
